## 1. 개발 의도

이 앱을 왜 만들게 되었나요? 어떤 불편함이나 필요를 발견했나요?

-이 앱은 '과연 내가 게임을 만들 수 있을까?'라는 의문에서 시작되었습니다.

이 게임은 누구나 쉽게 플레이할 수 있어 어렵고 복잡한 게임으로 스트레스를 받을 필요 없이 편안하게 즐길 수 있다는 장점이 있습니다.
